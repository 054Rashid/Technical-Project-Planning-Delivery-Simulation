# Delivery Roadmap

| Phase | Weeks | Key outcome | Gate |
|---|---|---|---|
| Initiation | 1 | Charter, sponsor, success criteria | G1: Charter approved |
| Discovery | 2–3 | Requirements and current-state map | G2: Requirements baselined |
| Data foundation | 4–6 | Data contracts and validation | G3: Data readiness |
| ML lifecycle | 5–9 | Experiment tracking and model gates | G4: Model readiness |
| Platform integration | 8–12 | Feature/deployment/monitoring path | G5: Technical readiness |
| Pilot/UAT | 13–14 | Business validation | G6: UAT sign-off |
| Go-live & handover | 15–16 | Pilot release and operations handover | G7: Close |

## Critical dependencies

1. Historical sales data availability before Week 4.
2. Kubernetes environment before Week 8.
3. Security review before production pilot.
4. Third-party data feed confirmation before UAT.
5. Business SME availability during Weeks 13–14.

## Critical path

Requirements → data readiness → baseline model → experiment tracking → platform integration → UAT → pilot release.
