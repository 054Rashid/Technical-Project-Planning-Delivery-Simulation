## Capacity approach

Capacity is planned by role and peak delivery period rather than by individual employee identity. The Project Manager monitors whether critical-path work has sufficient capacity and escalates conflicts before they affect milestone commitments.

## Cost-control decisions

- Protect critical-path engineering capacity.
- Use contingency only for approved changes or material delivery risks.
- Defer non-essential scope when it threatens release timing.
- Review forecast-to-complete during each steering cycle.
