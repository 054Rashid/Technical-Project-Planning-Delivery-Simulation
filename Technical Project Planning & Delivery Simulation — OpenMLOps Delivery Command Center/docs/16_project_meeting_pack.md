# Project Meeting Pack

## Weekly Delivery Review — Standard Agenda

**Duration:** 45 minutes

1. Previous actions and overdue items — 5 min
2. Schedule and milestone status — 5 min
3. Workstream progress — 10 min
4. Risks, issues and dependencies — 10 min
5. Scope / change requests — 5 min
6. Decisions required — 5 min
7. Next-period commitments — 5 min

## Decision log format

| Decision | Context | Options | Decision owner | Date | Outcome |
|---|---|---|---|---|---|
| Deployment hardening before UAT | Security feedback could affect pilot | Deploy first / harden first | Engineering Lead | Week 8 | Harden first |
| Dashboard enhancement | Useful but not required for acceptance | Include / defer | Product Owner | Week 13 | Defer |

## Action-tracking standard

Every action should contain:

- clear owner;
- due date;
- expected deliverable;
- dependency, if applicable;
- status;
- escalation path if overdue.
