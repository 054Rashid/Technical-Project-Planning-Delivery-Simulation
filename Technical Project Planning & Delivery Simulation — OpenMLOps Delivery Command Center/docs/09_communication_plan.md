# Communication Plan

| Audience | Meeting / artifact | Frequency | Purpose | Owner |
|---|---|---|---|---|
| Sponsor | Executive status summary | Bi-weekly | Decisions, risks, progress | Project Manager |
| Core team | Delivery stand-up | 2x weekly | Blockers and immediate actions | Project Manager |
| Engineering | Technical review | Weekly | Architecture, dependencies, quality | Engineering Lead |
| Data/ML | Workstream review | Weekly | Data/model readiness | Project Manager |
| Business SMEs | Requirements/UAT session | Weekly during UAT | Validation and feedback | Product Owner |
| Security | Readiness review | At gates | Control validation | Security Lead |
| Operations | Handover review | Weeks 14–16 | Support readiness | Operations Lead |

## Status-reporting standard

Every weekly report contains:

1. overall health;
2. milestone status;
3. completed work;
4. next-period commitments;
5. top risks/issues;
6. decisions needed;
7. changes to baseline;
8. KPI trend.
